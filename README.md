# Employee Management System

## Overview
A Django-based employee management portal with authentication,
role-based authorization, employee CRUD operations, search,
filtering and dashboard reporting.

## Features
- Authentication
- Role-based permissions
- Employee CRUD
- Department management
- Search and filtering
- Dashboard
- Validation
- Responsive UI

## Tech Stack
- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite/PostgreSQL
- Git
